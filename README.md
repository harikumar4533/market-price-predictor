# Market Price Predictor

A beginner-friendly Machine Learning project that predicts a market closing price from Open, High, Low, and Volume.

## Files

- data.csv - sample market data
- train.py - trains the model
- predict.py - makes predictions
- app.py - Streamlit application
- requirements.txt - required libraries

## Run

Install libraries:

python -m pip install -r requirements.txt

Train the model:

python train.py

Run the application:

python -m streamlit run app.py

This is an educational project and is not financial advice.
